# The ops loop

The core habit: a passing thought becomes structured knowledge without you deciding where it goes.

1. **Capture** — `ops capture "…"` drops it into `inbox/`. Zero decisions.
2. **Triage** — `ops triage` proposes a home (a task or a wiki note); you approve. Overrides teach it
   a filing rule, so it gets better at *your* judgment over time.
3. **It lands** — either a tracked task (`tasks/active/…`, where the folder *is* the status) or a
   durable note here in the wiki, auto-linked into the graph.
4. **Bookend the day** — `ops start` opens the journal and carries forward open work; `ops close`
   summarizes it. Nothing is lost; everything is a git diff.

Every step is one of the [[risk-classes]] the guardrail enforces, so the same loop is safe to run by
hand, on a schedule, or through an AI agent. See [[conventions]] for the note shape, and [[welcome]]
to get started.
