# Personal OS — optional dependencies.
#
# Stage-1 search (ops index/search, keyword + wikilink graph) needs NOTHING beyond Python 3.9+
# stdlib (sqlite3 with FTS5). The deterministic test suites are stdlib-only too.
#
# WHICH interpreter: `ops` dispatches via BARE `python3` on your PATH (see the `ops` script). These
# packages must be importable by THAT interpreter — not some other venv. If you use a venv, put its
# bin first on PATH (e.g. `export PATH="$OPS_HOME/.venv/bin:$PATH"`), install there, and confirm with
# `ops doctor` (it prints "optional: lancedb present"). With OPS_VECTORS=1 but lancedb missing, `ops
# index` warns and falls back to keyword-only — it never crashes; it just won't build vectors.
#
# Stage-2 vectors (OPS_VECTORS=1) — the scale-grade semantic layer (ADR-006) — needs:
lancedb>=0.33          # embedded, file-based ANN vector store (no server). pip install lancedb
#
# Stage-3 rerank (OPS_RERANK=1) — local cross-encoder precision layer (ADR-006):
fastembed>=0.4         # ONNX runtime, no torch; auto-picks jina-reranker-v2-base-multilingual
#
# ...plus a local embedder, NOT a pip dep: a running Ollama with the model pulled —
#   ollama pull embeddinggemma         # default (ADR-005); or bge-m3 / qwen3-embedding:0.6b
# Override the model with OPS_EMBED_MODEL. Everything stays local/offline; no cloud, no server.
#
# Bookmark extraction (ops bookmark) — optional local upgrade. Without it, `ops bookmark` still
# works (built-in crude strip); with it you get real main-content article → Markdown, all local:
trafilatura>=2.0       # best-in-class local extractor (drops nav/ads, native MD). Auto-detected.
